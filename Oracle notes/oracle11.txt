LOOPS 
=======
We have three types of LOOPS in PL/SQL.

1) Simple Loop 

2) While Loop 

3) For Loop 

1) Simple Loop 
--------------
It is used to evaluate the code how long our condition is true.

ex:
	DECLARE 
	A number:=1;
	BEGIN 
	DBMS_OUTPUT.PUT_LINE('Welcome');

	LOOP
	DBMS_OUTPUT.PUT_LINE('Hello');
	EXIT WHEN A=4;
	A:=A+1;
	END LOOP;

	DBMS_OUTPUT.PUT_LINE('Thank You');
	END;
	/

2) While Loop 
-------------
It is used to evaluate the code how long our condition is true.

ex:
	DECLARE 
	A number:=1;
	BEGIN
	DBMS_OUTPUT.PUT_LINE('Welcome');

	WHILE A<=4 LOOP
	DBMS_OUTPUT.pUT_LINE('Hello');
	A:=A+1;
	END LOOP;

	DBMS_OUTPUT.PUT_LINE('Thank You');	
	END;
	/		

3) For Loop 
-----------
It is used to iterate the code how long our condition is true.

ex:
	DECLARE 
	A number;
	BEGIN 
	DBMS_OUTPUT.PUT_LINE('Welcome');
	FOR A IN 1..4 LOOP
	DBMS_OUTPUT.PUT_LINE('Hello');	
	END LOOP;
	DBMS_OUTPUT.PUT_LINE('Thank You');
	END;
	/

Exceptions 
==========
Runtime errors are called known as exceptions.

We have two types of exceptions.

1) Predefined exceptions 

2) Userdefined exceptions 

1) Predefined exceptions 
------------------------
We have following built-in exceptions in PL/SQL.

1) NO_DATA_FOUND exception 

2) TOO_MANY_ROWS exception 

3) ZERO_DIVIDE exception 

4) VALUE_ERROR exception 

5) DUP_VAL_ON_INDEX exception 

6) OTHERS 

1) NO_DATA_FOUND exception 
--------------------------
This exception will occur when select statement does not return any row.

ex:
	DECLARE 
	L_ename emp.ename%TYPE;
	BEGIN 
	select ename into L_ename from emp where eid=209;
	DBMS_OUTPUT.PUT_LINE(L_ename);	
	EXCEPTION 
	WHEN NO_DATA_FOUND THEN 
	DBMS_OUTPUT.PUT_LINE('Employee Id Not Found');
	END;
	/ 
	
2) TOO_MANY_ROWS exception 
--------------------------
This exception will occur when select statement returns more then one row.

ex:
	DECLARE 
	L_ename emp.ename%TYPE;
	BEGIN 
	select ename into L_ename from emp where deptno=10;
	DBMS_OUTPUT.PUT_LINE(L_ename);	
	EXCEPTION 
	WHEN TOO_MANY_ROWS THEN 
	DBMS_OUTPUT.PUT_LINE('Too Many Records');
	END;
	/ 
	
3) ZERO_DIVIDE exception 
---------------------
This exception will occur when we are trying to divide a number with zero.		
ex:
	DECLARE 
	N number;
	BEGIN
	N:=10/0;
	DBMS_OUTPUT.PUT_LINE(N);
	EXCEPTION 
	WHEN ZERO_DIVIDE THEN 
	DBMS_OUTPUT.PUT_LINE('Dont divide by zero');
	END;
	/

4) VALUE_ERROR exception 
--------------------------
This exception will occur when there is a mismatch with datatype or size.

ex:
	DECLARE 
	A number(3);
	BEGIN 
	A:=12345;
	DBMS_OUTPUT.PUT_LINE(A);
	EXCEPTION 
	WHEN VALUE_ERROR THEN 
	DBMS_OUTPUT.PUT_LINE('Check the size');	
	END;
	/
ex:
---
	DECLARE 
	L_esal emp.esal%TYPE;
	BEGIN 
	select ename into L_esal from emp where eid=201;
	DBMS_OUTPUT.PUT_LINE(L_esal);	
	EXCEPTION 
	WHEN VALUE_ERROR THEN 
	DBMS_OUTPUT.PUT_LINE('Datatype Not Matched');
	END;
	/ 
	
5) DUP_VAL_ON_INDEX exception
-----------------------------
This exception will occur when we are trying to insert duplicate in primary key.

ex:
	alter table emp ADD primary key(eid);

	BEGIN
	insert into emp values(201,'laxmi',34000,60,'developer',500);
	DBMS_OUTPUT.PUT_LINE('Record Inserted');
	EXCEPTION 
	WHEN DUP_VAL_ON_INDEX THEN 
	DBMS_OUTPUT.PUT_LINE('Duplicates not allowed');
	END;
	/

6) OTHERS 
---------
It is a universal exception angular which is used to handle all types of exceptions.

ex:
	
ex:

	select ename into L_ename from emp where eid=209;

Cursors 
=======
A cursor is a pointer to a specific memory area called context area, which stores the result set of an executed SQL query.

We have two types of cursors in PL/SQL.

1) Implicit cursors 

2) Explicit cursors

1) Implicit cursors 
--------------------
All the activities related to cursors like opening the cursor, processing the cursor, closing the cursor which is done automatically are called implicit cursors.

We have four types of implicit cursor attributes.

i) SQL%ISOPEN
-------------
	It is a boolean attribute which always returns false.

ii) SQL%FOUND 
-------------
	It is a boolean attribute which returns true if SQL command is success and 
	returns false is SQL command is failed.

iii) SQL%NOTFOUND 
-------------
	It is completely inverse of SQL%FOUND.
	It is a boolean attribute which returns false if SQL command is success and 
	returns true is SQL command is failed.

iv) SQL%ROWCOUNT 
-----------
	It returns number of records effected in a database table.


i) SQL%ISOPEN
--------------
	BEGIN 
	IF SQL%ISOPEN THEN 
	DBMS_OUTPUT.PUT_LINE('Cursor opened');
	ELSE
	DBMS_OUTPUT.PUT_LINE('Cursor Closed');
	END IF;
	END;
	/

ii) SQL%FOUND 
------------
	BEGIN 
	update student set sname='ramana' where sno=103;
	IF SQL%FOUND THEN 
	DBMS_OUTPUT.PUT_LINE('Record Updated');
	ELSE
	DBMS_OUTPUT.PUT_LINE('Record Not Updated');
	END IF;
	END;
	/

iii) SQL%NOTFOUND
-----------------
	BEGIN 
	update student set sname='raju' where sno=109;
	IF SQL%NOTFOUND THEN 
	DBMS_OUTPUT.PUT_LINE('Record Updated');
	ELSE
	DBMS_OUTPUT.PUT_LINE('Record Not Updated');
	END IF;
	END;
	/

iv) SQL%ROWCOUNT 
---------------
	BEGIN 
	update student set sname='raju';
	DBMS_OUTPUT.PUT_LINE(SQL%ROWCOUNT||' Records Updated');
	END;
	/
