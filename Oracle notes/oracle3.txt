update command 
==============
It is used to modify the rows which are present in database table.

syntax:
-------
	update <table_name> set <col_name>=value where condition;
ex:
	update student set sname='Alan' where sno=105;
	update student set sadd='delhi' where sname='ramana';		
	update student set sadd='vizag' where sno=102;
	update student set sname='rani',sadd='texas' where sno=101;
	commit;

Note:
-----
	If we won't use where clause then all rows will be updated.
ex:
	update student set sno=101;
	update student set sname='raja';
	update student set sadd='delhi';


delete command 
===============
It is used to delete the rows from database table.

syntax:
-------
	delete from <table_name> where condition;
eX:
	delete from student where sno=105;		
	delete from student where sname='ramana';
	delete from student where sadd='delhi';
	commit;

Note:
-----
	If we won't use where clause then all rows will be deleted.
	ex:
		delete from student;
		delete from dept;
		delete from emp;

Logical Operators 
=================
Logical operators are used to declare multiple conditions in our query.

We have three logical operators.

1) AND 

2) OR 

3) NOT 

1) AND 
---------
It is used to combine all the conditions and returns the rows if all conditions are true.
Here conditions must be from same row. 

ex:
	select * from emp where eid=201 and ename='Alan';

	select * from emp where eid=201 and ename='Jessica'; --no rows selected 
	
	select * from emp where eid=209 and ename='Alan';    --no rows selected 	

	select * from emp where eid=201 and ename='Mark';    --no rows selected 	

2) OR 
------
It is used to combine all the conditions and returns the rows atleast one condition is true.Here conditions can be from any row.

ex:
	select * from emp where eid=201 OR ename='Alan';  -- 1 record 

	select * from emp where eid=201 OR ename='Jessica';  -- 1 record 
	
	select * from emp where eid=209 OR ename='Alan';    --  1 record 	

	select * from emp where eid=201 OR ename='Mark';    -- 2 record 	

3) NOT
-------
It is a reverse of condition.
It returns the rows exception the condition.
A '<>' denoted as not operator.
ex:
	select * from student where NOT sname='raja';	
	select * from student where  sname<>'raja';	

	select * from student where NOT sno=104;
	select * from student where  sno<>104;
	
Between Operator 
================
Between operator is used to return the records those who are matching in the range of values.

In between operator first we need to declare lower limit then higher limit.

Between operator is applicable only for numbers.

ex:
	select * from student where sno between 101 and 105;
	select * from student where sno between 105 and 101; -- no rows selected 
	select * from emp where esal between 10000 and 30000;


IN Operator 
============
IN operator is a replacement of OR operator.
It is used to return the records those who are in the list of values.
ex:
	select * from student where sno IN (101,102,103,109);
	select * from student where sname in ('raja','ramana','raj');

Pattern Matching operators 
=========================
It is used to select the letters from database table.

We have two types of pattern matching operators.

1) Percentage(%)

2) Underscore(_)

1) Percentage(%)
----------------

Q) Write a query to display employees information whose name starts with 'A' letter?

	select * from emp where ename like 'A%';

Q) Write a query to display employees information whose name ends with 'n' letter?

	select * from emp where ename like '%n';

Q) Write a query to display employees information whose name having middle letter as 'l'?

	select * from emp where ename like '%l%'; 


2) Underscore(_)
----------------

Q) Write a query to display employees information whose employee name having second letter as 'l'?

	select * from emp where ename like '_l%';


Q) Write a query to display employees information whose employee name having third 
   letter as 'r'?

	select * from emp where ename like '__r%';


Q) Write a query to display employees information whose employee name having 
   second last letter as 'i'?

	select * from emp where ename like '%i_';


DDL commands 
============
1) create - tables 
2) alter  - columns  
3) drop 
4) truncate 
5) rename 


2) alter command 
================
Using alter command we can perform following activities.

i) Adding new columns 

ii) Modifying existing columns 

iii) Dropping the columns 

iv) Renaming the columns 

i) Adding new columns
---------------------
Using alter command we can add new columns in existing table.

syntax:
-------
	alter table <table_name> ADD (col datatype(size));

ex:
	alter table student ADD (state varchar2(12),pincode number(8));
	update student set state='Telangana' where sno=101; 

ii) Modifying existing columns 
--------------------------------
Using alter command we can modify the columns.
We can increase or decrease the size only when existing values are fit into new size.
We can change the datatype of a column only when that column is empty.

syntax:
-------
	alter table <table_name> MODIFY (col datatype(size));
ex:
	desc  student;
	alter table student modify (state varchar2(15));
	desc  student;
	alter table student modify (pincode varchar2(8));
	

iii) Dropping the columns 
------------------------
Using alter command we can drop the columns.

syntax:
------
	alter table <table_name> DROP (col1,col2,...,colN);
ex:
	alter table student DROP(state,pincode);

iv) Renaming the columns 
------------------------
Using alter command we can rename the column.

syntax:
--------
	alter table <table_name> rename column <old_name> to <new_name>;
ex:
	alter table student rename column sadd to city;
	alter table emp rename column esal to dailywages;
	alter table emp rename column job to designation;
