4) Foreign Key 
==============
A foreign key is used to establish the relationship between two tables.

This relationship is also known as parent and child relationship or master and detailed relationship.

To establish relationship between two tables. A parent table must have primary key or unique key and child table must have foreign key.

Foreign key will accept only those values which are present in primary key.

Primary key and foreign key name may or may not match but datatype must match.

Foreign key accept duplicates and null values.

Diagram: oracle6.1


college table 
------------
drop table college;
create table college(sno number(3) primary key,sname varchar2(10),sdept varchar2(10));
insert into college values(101,'raja','CSE');
insert into college values(102,'ravi','ECE');
insert into college values(103,'ramana','MEC');
commit;

library table 
-------------
drop table library;
create table library(roll_no number(3) REFERENCES college(sno), book_name varchar2(12));
insert into library values(101,'Java');
insert into library values(102,'Oracle');
insert into library values(103,'SpringBoot');
insert into library values(103,'HTML');
insert into library values(null,'CSS');
commit;

To drop the tables first we need to drop child table then parent table.
ex:
	drop table library;
	drop table college;

5) Check 
=========
It describes domain of a column.

Here domain means what type of a value a column must accept.

Check contraint can be created at column level and table level.

column level 
------------
drop table student;
create table student(sno number(3),sname varchar2(10),smarks number(3) check (smarks<=100));
insert into student values(101,'raja',87);
insert into student values(102,'ravi',100);
insert into student values(103,'ramana',389); -- invalid 
commit;

column level 
------------
drop table student;
create table student(sno number(3),sname varchar2(10),
				smarks number(3) check (smarks between 0 and 100));
insert into student values(101,'raja',87);
insert into student values(102,'ravi',100);
insert into student values(103,'ramana',389); -- invalid 
commit;

column level 
------------
drop table student;
create table student(sno number(3),sname varchar2(10) check(sname=upper(sname)),
					smarks number(3));
insert into student values(101,'RAJA',87);
insert into student values(102,'ravi',79); -- invalid 
insert into student values(103,'RaMaNa',91); -- invalid 
commit;


column level 
------------
drop table student;
create table student(sno number(3),sname varchar2(10) check(sname=lower(sname)),
					smarks number(3));
insert into student values(101,'RAJA',87); -- invalid 
insert into student values(102,'ravi',79); 
insert into student values(103,'RaMaNa',91); -- invalid 
commit;


table level 
------------
drop table student;
create table student(sno number(3),sname varchar2(10),smarks number(3), 
 						check(sname=lower(sname)));
insert into student values(101,'RAJA',87); -- invalid 
insert into student values(102,'ravi',79); 
insert into student values(103,'RaMaNa',91); -- invalid 
commit;

Q) What is the difference between ROWID and ROWNUM ? 

ROWID
--------
It is permanent.
It is a memory location where our records are storing in a table.
ex:
	select rowid,eid,ename,esal from emp;


ROWNUM 
------
It is temperory.
It gives row numbers which starts with 1 and increment by 1.
ex:
	select rownum,eid,ename,esal from emp;
	select rowid,rownum,eid,ename,esal from emp;

Sequence 
========
A sequence is an object which is used to generate the numbers.

syntax:
------
	create sequence <sequence_name> start with value increment by value;

We have two pseudo for sequence.

1) NEXTVAL
-----------
	It is used to generate next number is a sequence.
	ex:
		create sequence sq1 start with 101 increment by 1;

		drop table student;
		create table student(sno number(3),sname varchar2(10),sadd varchar2(12));
		insert into student values(sq1.NEXTVAL,'Alan','Florida');
		insert into student values(sq1.NEXTVAL,'Jose','Texas');
		insert into student values(sq1.NEXTVAL,'Linda','Chicago');
		commit;

2) CURRVAL  
-------------
	It returns last number generated by sequence.
	ex:
		select sq1.CURRVAL from dual;


Q) Write a query to see the list of sequences present in database?

	select sequence_name from user_sequences;


Q) Write a query to drop the sequence?

	drop sequence sq1;
